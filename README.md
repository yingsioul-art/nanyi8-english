# 南一版 國中英語 第三冊（八上）Lesson 1・Lesson 2・Review 1 學習站

單檔離線互動網頁，給家裡的孩子複習用。用瀏覽器開 `index.html` 就能用，手機也可以。

**線上版（也是安裝點）**：https://yingsioul-art.github.io/nanyi8-english/

## 裝成手機 app（裝好之後**完全不需要網路**）

| 手機 | 怎麼裝 |
|---|---|
| Android／Chrome | 開上面網址 → 頁首「📲 安裝到手機主畫面」按鈕 → 裝好 |
| iPhone／Safari | 開上面網址 → 下方 **分享** → **加入主畫面** |

裝好後主畫面會有獨立圖示，點開是全螢幕、**離線可用**（Service Worker 用 cache-first 策略，
開了先吃快取、有網路時才在背景更新）。

**離線時哪些能用？**

| 功能 | 離線 |
|---|---|
| 課本教學（11 段）、會考重點、小考五關 | ✅ 完全可用 |
| 🎧 認識單字、🎯 聽力測驗、✍️ 拼字練習 | ✅ 可用（語音合成是手機內建的） |
| 🎤 口說練習 | ⚠️ 自動改成「自我評估模式」（語音辨識是雲端服務，一定要連網）；發音示範仍可聽 |
| 📺 課本 QR 官方影音 | ❌ 需要網路（YouTube／Drive 連結） |

離線時頁首會出現一條提示，說明哪兩項會降級。

## 不想用網址也可以

`index.html` 是**單一檔案**，把它傳到手機（LINE、Email、雲端硬碟都行），
用瀏覽器開也能用——除了口說辨識與課本影音之外，其他功能一樣完整。

## 內容

| 分頁 | 內容 |
|---|---|
| 📘 課本教學 | Lesson 1／Lesson 2／Review 1 各分「單字→片語→文法→課文句型」四段，用講課的口吻寫，順序與小考一致 |
| 🔍 會考重點 | 四種時態怎麼選／why·because·so 的實際份量／單字分兩類／**這一課該把力氣花在哪**（附官方數據與會考題型長相） |
| 🔤 單字練習 | 🎧 認識單字（TTS＋課本例句）／🎯 聽力測驗（聽發音選中文）／✍️ 拼字練習（聽音拼字）／🎤 口說練習（語音辨識） |
| ✏️ 小考 | 五關：單字／片語／文法／課文句型／2000 單字，答錯即時給解析、考點與出處 |

- 89 個單字片語，每個都附**課本原文例句**並標出處頁（例：`L1 Dialogue p.3`）。
- 發音、聽力、口說一律用瀏覽器內建語音（Web Speech API）；**口說辨識需要 Chrome 與麥克風權限**。
- 進度存在瀏覽器 localStorage，換裝置不會同步。

## 教學重點是怎麼排的

不是照課本順序，是照**會考數據**排的。把 111–115 年會考英語閱讀的官方試題分析全部拆開來算（215 題，每題都有官方標註的評量目標）：

| 考點 | 佔比 | 平均通過率 |
|---|---:|---:|
| 字彙／片語（單題） | 26.5% | 0.645 |
| 文法（單題） | 18.6% | **0.559** |
| 閱讀理解（題組） | 40.9% | — |
| 克漏字 | 9.3% | 0.561 |

單題（字彙＋文法）合起來 45%，正好是小考範圍；而**文法單題的通過率比多數閱讀理解題還低**，是投報率最高的一塊。這兩課裡直接命中會考文法單題的是「一般動詞過去式＋did 問句」（6/40 題，平均通過率 0.543）。

## 資料來源與版權

- 教材內容（單字、例句、課文句型、Review 1 文法表）**取自南一版國中英語第三冊課本**；小考題目取材自**南一版習作**並改寫為選擇題。
- 會考部分**只引用官方題號與選項組合，未轉載試題內容**；統計數字來自國家教育研究院心測中心公開的試題分析報告。
- **本站為個人學習複習用途，非營利、不販售、不代替課本。** 課本與習作之著作權屬南一書局所有。
  如著作權人認為不妥，請開 issue 告知，將立即下架。
- 課本 QR code 的官方影音（課文動畫、發音音檔）以**外部連結**形式提供，未重製、未轉存。

## 給孩子的使用建議

1. 先到「📘 課本教學」把 Lesson 1 的「單字」和「文法」看過（不強制，小考沒有上鎖）。
2. 「🔤 單字練習」四種輪流練——**拼字和口說最容易被忽略，但段考和會考都會考到**。
3. 「✏️ 小考」五關依序，答對 80% 開下一關；答錯時看考點與出處，回課本對照。
4. 最後再看「🔍 會考重點」的最後一段，知道力氣該花在哪。
